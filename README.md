# listmate-downloads

## Download ListMate for Windows

**[Download ListMate](https://github.com/digixzain/listmate-downloads/releases/latest/download/ListMate-Setup.exe)**

A valid ListMate account, active access and an approved computer are required.

Already using ListMate? Close the app and its browser profiles before installing. Use the same Windows account to retain your saved data.

[Release notes and checksums](https://github.com/digixzain/listmate-downloads/releases/latest)

The installer is currently not Authenticode-signed. Windows may display an unverified-publisher warning.
